# 试用说明（给第一次使用的朋友）

这份说明不需要任何编程基础。整个试用大约 **3–5 分钟**，全程免费，不需要注册账号，数据不会离开你的电脑。

试用目标：在 Grok Bot 里复制 2 段回复 → 生成一个「空间」文件 → 发给自己（微信 / 飞书「文件传输助手」）→ 打开看看效果。

---

## 一、macOS

### 1. 准备（只需一次）
1. 打开「终端」（启动台里搜索「终端」）。
2. 输入下面这行并回车，按提示点「安装」（这是苹果官方的免费开发工具，约几分钟）：
   ```bash
   xcode-select --install
   ```
   如果提示「已经安装」，直接进行下一步。

### 2. 安装
1. 双击解压 `GrokClipSpace.zip`。
2. 在终端输入 `cd `（cd 后面有一个空格），然后把解压出来的 `GrokClipSpace` 文件夹**拖进终端窗口**，回车。
3. 输入下面这行并回车：
   ```bash
   bash install.sh
   ```
4. 看到「✓ 已启动」后，屏幕右侧会出现一个**紫色悬浮球**，顶部菜单栏多一个 ✦ 图标。

### 3. 如果提示「无法打开」「无法验证开发者」
用 `install.sh` 在自己电脑上编译的 App 一般不会被拦截。如果你拿到的是**别人编译好的 App**，macOS 的安全机制（Gatekeeper）可能会拦截，处理方法：

- 打开「系统设置 → 隐私与安全性」，滚动到最下面，找到关于「GrokClip Space」的提示，点 **「仍要打开」**，输入开机密码确认。
- 较早版本的 macOS 也可以：在「应用程序」里**右键**点 App → 选「打开」→ 再点「打开」。

这是因为本项目不花钱购买苹果开发者证书，只做了本机签名（ad-hoc），不代表程序有问题。最稳妥的方式仍然是用 `bash install.sh` 自己编译。

### 4. 第一次监听「下载」文件夹
如果弹出「GrokClip Space 想访问下载文件夹」，请点「允许」，这样下载的文件才能自动挂上。

## 二、Windows

> Windows 版目前还**没有在真机上完整测试过**，非常欢迎你帮忙试用并反馈。

### 1. 安装 Python（只需一次，免费）
1. 打开 [python.org 的 Windows 下载页](https://www.python.org/downloads/windows/)，下载最新的 Python 3 安装包（Windows installer 64-bit）。
2. 运行安装包时，**一定勾选底部的「Add python.exe to PATH」**，然后点「Install Now」。默认会包含「tcl/tk」，不要取消。
3. 安装包来自 python.org 官方，如果浏览器或系统提示「是否保留 / 是否运行」，选择保留和运行即可。

### 2. 运行
1. 右键 `GrokClipSpace.zip` →「全部解压缩」。
2. 打开解压后的 `GrokClipSpace\crossplatform` 文件夹，**双击 `run_windows.bat`**。
3. 如果出现蓝色的「Windows 已保护你的电脑」（SmartScreen）：点 **「更多信息」→「仍要运行」**。这是因为脚本没有购买代码签名证书，脚本本身只是用 Python 启动程序，可以用记事本打开查看内容。
4. 屏幕右侧出现**紫色悬浮球**就说明启动成功。

想要「开始」菜单快捷方式或开机自启，见 [README 的 Windows 安装](../README.md#windows)。

### 3. 双击没反应？
在同一个文件夹的地址栏输入 `cmd` 回车，在黑色窗口里输入：
```bat
run_windows.bat --console
```
把窗口里显示的文字截图发给我们（见文末「如何反馈」）。

## 三、Linux

1. 打开终端，按你的系统安装依赖（需要输入开机密码）：
   ```bash
   # Ubuntu / Debian / 深度 / 统信 UOS 等
   sudo apt install python3 python3-tk xclip xdotool wl-clipboard
   # Fedora
   sudo dnf install python3 python3-tkinter xclip xdotool wl-clipboard
   # Arch / Manjaro
   sudo pacman -S python tk xclip xdotool wl-clipboard
   ```
2. 解压 `GrokClipSpace.zip`，在终端进入 `GrokClipSpace/crossplatform`，运行：
   ```bash
   bash run_linux.sh --check    # 检查依赖，全部 ✓ 最好
   bash install_linux.sh        # 加到应用菜单并启动
   ```
3. 屏幕右侧出现紫色悬浮球即成功。

> **Wayland 桌面**（较新的 Ubuntu / Fedora 默认）：系统不允许程序判断你在哪个软件里复制，所以会改成「所有软件的复制都收录」，收集篮顶部会有黄色提醒。复制密码前可以先点「暂停监听」。

## 四、开始试用（所有系统相同）

1. **收录**：打开 Grok Bot，找两条回复，分别点回复下方的「复制」按钮。悬浮球每次会弹一下，提示 `+1 已收录 #01`、`#02`。
2. **（可选）挂文件**：在对话里下载一个文件，它会自动挂到刚才那条原文下面。
3. **打开收集篮**：单击悬浮球。可以勾选、用 ↑ ↓ 排序、填写标题。
4. **生成空间**：点紫色的「一键生成空间并复制」。
5. **转发**：打开微信或飞书的「文件传输助手」，按 `⌘V`（Mac）或 `Ctrl+V`（Windows / Linux），发出去的是一个 `.html` 文件。
6. **查看**：在另一台电脑或手机上打开这个文件，看看原文顺序、格式、图片和附件是否完整。

另外也可以试试「复制纯原文」：粘贴出来应该和 Grok 里的原文一字不差。

### 小提示
- 悬浮球可以拖动；右键（Mac 在菜单栏图标）有完整菜单。
- 悬浮球右下角绿点表示正在监听，灰点表示暂停或缺少组件。
- 生成的空间文件默认保存在主目录下的 `grok bot` 文件夹（如果有），否则在桌面的 `GrokSpaces` 文件夹。

## 如何反馈

最好的方式是在项目的 GitHub 页面提交 **Issue**（选择「问题反馈」或「功能建议」模板）。请写清楚：

1. 系统和版本（例如 Windows 11 23H2、Ubuntu 24.04 Wayland、macOS 15）
2. 你做了什么、期望看到什么、实际看到什么
3. 截图或错误文字（Windows 可用 `run_windows.bat --console` 获取）
4. 程序错误日志（如有）：Windows 在 `%APPDATA%\GrokClipSpace\error.log`，Linux 在 `~/.local/share/GrokClipSpace/error.log`。日志里只有程序错误，不含你复制的内容

**请不要在反馈里附上真实的对话内容、生成的空间文件或公司内部资料。** 如需演示，请用无关的测试文字。

安全相关的问题（例如可能泄露数据的漏洞）请不要公开提交，按 [SECURITY.md](../SECURITY.md) 私下报告。
